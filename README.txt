# RemontSite — сайт Сергея Негары

## Структура

- `index.html` — основная страница
- `css/style.css` — стили
- `js/script.js` — анимации, меню, счётчик, активная навигация, lightbox
- `images/` — фотографии

## Важно

В папке `images` должны находиться:

- `work1.jpg` ... `work24.jpg`
- `book.jpg`
- `kubok1.jpg`
- `kubok2.jpg`

Главное фоновое изображение первого экрана — `work5.jpg`.

## Запуск

Просто открой `index.html` в браузере.

Для разработки удобнее открыть папку в VS Code и использовать Live Server.

## Что уже реализовано

- адаптивная версия для телефона;
- burger-меню;
- плавная прокрутка;
- появление блоков при прокрутке;
- анимированный счётчик 20+;
- уменьшающаяся шапка;
- автоматическая подсветка активного раздела;
- кнопка «Наверх»;
- прелоадер;
- галерея с полноэкранным просмотром;
- стрелки и управление галереей клавиатурой.
